# Alien Guns (Fabric, Minecraft 26.3)

8 инопланетных пушек. ПКМ — выстрел. Вся логика на сервере, анимации на ванильных частицах
(кастомных рендереров нет, поэтому мод меньше ломается между версиями).

| Предмет | Что делает |
|---|---|
| `black_hole_cannon` | снаряд -> чёрная дыра на 7 сек (диск, джеты, спираль материи, затягивает всё) -> коллапс и взрывная волна |
| `plasma_rifle` | быстрый плазменный луч, пробивает, поджигает |
| `gravity_pulser` | волна затягивает всех внутрь, потом выбрасывает наружу |
| `rift_blaster` | два вращающихся портала и телепорт в точку, куда целишься |
| `nova_emitter` | медленный шар -> звёздная сфера схлопывается -> сверхновая |
| `arc_rifle` | цепная молния, прыгает до 6 целей |
| `void_lance` | луч + «разрыв пустоты», 4 сек тянет и калечит (даёт Тьму) |
| `stasis_ray` | ледяная сфера замораживает всех на 5 сек, потом разбивается |

Взять: творческий режим, вкладка «Бой», или `/give @s alienguns:black_hole_cannon`.

## Сборка
1. Установи JDK 25.
2. Нужен Gradle wrapper. Проще всего: на https://fabricmc.net/develop/template/ сгенерируй шаблон для 26.3,
   скопируй из него `gradlew`, `gradlew.bat` и папку `gradle/` сюда. Либо `gradle wrapper --gradle-version 9.3` (если установлен Gradle).
3. `./gradlew build` -> jar в `build/libs/alien-guns-1.0.0.jar`.
4. Положи jar и Fabric API 0.160.5+26.3 в `mods`.

Если `loom_version=1.17-SNAPSHOT` не находится — поставь актуальную версию Loom из шаблона.

## Настройка
`Fx.DENSITY` (в `Fx.java`) — множитель количества частиц. Если лагает — поставь 0.5.
Параметры каждой пушки (радиус, урон, время) — в `Effects.java` и `Guns.java`.
